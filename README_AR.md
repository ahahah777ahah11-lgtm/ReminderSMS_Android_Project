# رسائل مديونية العملاء — نسخة أولية لأندرويد

## الميزات
- استيراد العملاء من ملف CSV.
- عرض الاسم ورقم الهاتف والمبلغ «له» والمبلغ «عليه» والصافي.
- فلترة العملاء الذين عليهم مديونية.
- إضافة حركة مالية على العميل أو له.
- تجهيز وإرسال رسالة SMS لكل عميل مدين بعد تأكيد المستخدم.

## تنسيق ملف الاستيراد
صدّر بيانات دفتر الحسابات أو المحاسب الذكي برو إلى CSV، واجعل الصف الأول أسماء الأعمدة. يدعم التطبيق أسماء شائعة مثل:
- الاسم / اسم العميل / name
- الهاتف / رقم الهاتف / الجوال / phone
- له / رصيد له / credit
- عليه / رصيد عليه / debt
- الرصيد / balance (إذا لم تتوفر أعمدة «له» و«عليه»، يُعامل الرصيد الموجب كمديونية)

مثال:
```csv
الاسم,رقم الهاتف,له,عليه
أحمد محمد,9677XXXXXXX,0,15000
علي صالح,9677YYYYYYY,2000,0
```
إذا كان الملف Excel (XLS/XLSX)، افتحه في Excel أو LibreOffice أو تطبيق الجداول ثم احفظ/صدّر نسخة CSV بترميز UTF-8.

## البناء
1. افتح المشروع في Android Studio حديث.
2. انتظر مزامنة Gradle.
3. من Build اختر Build APK(s).
4. ثبّت APK على هاتف Android، واسمح بإذن SMS عند الطلب.

## ملاحظات مهمة
- هذه نسخة أولية تحتاج تجربة على نسخة تصدير حقيقية من تطبيقات الحسابات قبل اعتمادها.
- الاستيراد الحالي CSV فقط؛ لا يقرأ قاعدة بيانات التطبيقات مباشرة.
- لا تُرسل رسائل جماعية إلا بعد مراجعة الأرقام والأرصدة والحصول على موافقة مناسبة من العملاء. قد تُحسب رسوم رسائل.
- الإرسال يعتمد على الشريحة والشبكة وصلاحيات أندرويد. النسخة لا تحفظ التعديلات بعد إغلاق التطبيق؛ يلزم إضافة قاعدة بيانات محلية قبل الاستخدام الإنتاجي.
- قد ترفض بعض إصدارات أندرويد أو سياسات المتجر توزيع تطبيقات ترسل SMS مباشرة؛ للاستخدام الشخصي يمكن اختبارها كتطبيق مثبت يدوياً.
